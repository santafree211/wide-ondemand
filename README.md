# wide-オンデマンド (Desktop Edition)

完全オンデマンド・常時稼働サーバー不要で稼働する、**「キーワード縦横展開＆Ubersuggest当たり判定システム」**の専用ローカルデスクトップUIです。

---

## 概要と特徴

1. **完全オンデマンド実行**:
   * 常時バックグラウンドで重いWebサーバーを立ち上げる必要がなく、必要なときだけ「`起動.bat`」をダブルクリックして起動できます。
2. **前後2大固定軸の完全対称性展開 (Rule 02)**:
   * シードキーワード（例: `はちみつレモン 体に悪い`）を入力すると、自動で `[A]` スロットと `[B]` スロットに分解。
   * 軸①（`[A] 〇〇` / 前固定）と軸②（`〇〇 [B]` / 後固定）をGUI上で編集・調整可能。
3. **25件バッチ閾値防護メーター (Rule 04)**:
   * Ubersuggest APIのチケット浪費を防ぐため、**合計25件集まるまでAPIコールを物理的に抑止**。
   * 「現在〇件 / 不足△件」をリアルタイム表示し、達成時のみメガバッチ実行ボタンが有効化されます。
4. **1-Shot メガバッチ検索 (Rule 04 & 05)**:
   * キャッシュに存在する語句は **API消費: 0回**。
   * 未キャッシュ語句＋シードを1つの巨大な配列にマージし、**たった1回のAPIコール**で最大100件を一網打尽に回収します。
5. **多層キャッシュ＆星判定テーブル (Rule 06)**:
   * 超穴場（☆☆☆）、本命当たり（☆☆）、手堅いロングテール（☆）を一覧判定。
   * Excel用CSVやMarkdownレポートをワンクリックで起動可能。

## ファイル構成（1責務1ファイル）

| ファイル名 | カテゴリ | 責務・役割 |
| :--- | :--- | :--- |
| **`起動.bat`** | entry | Python自動検知付きワンクリック起動バッチ |
| **`起動.vbs`** | entry | コンソール黒画面を出さずにGUI単体で起動するVBScript |
| **`core_config.py`** | core | パス解決、定数設定、UI配色テーマ集中管理 |
| **`core_logger.py`** | core | ファイル (`logs/`) および標準出力への統一ロギング |
| **`service_runner.py`** | service | PowerShellプロセスの非同期実行・リアルタイムログ転送・Kill制御 |
| **`service_data_manager.py`** | service | `wide` データストア（マスターDB/キャッシュ/生ログ）の読み取り・集計 |
| **`view_main_window.py`** | view | メインウィンドウ（Tkinter Tk）、ステータスヘッダー、タブ統合 |
| **`view_tab_expand.py`** | view | 【タブ1】キーワード展開、25件閾値メーター、メガバッチ実行 |
| **`view_tab_results.py`** | view | 【タブ2】リサーチ結果テーブル、星別絞り込み、CSV/レポート起動 |
| **`view_tab_database.py`** | view | 【タブ3】多層キャッシュ＆マスターDB検索、蓄積資産サマリー |
| **`view_tab_audit.py`** | view | 【タブ4】Ubersuggest API監査履歴、生JSONインスペクター |
